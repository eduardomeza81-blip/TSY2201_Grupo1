Descripción del proyecto
VetCloud SaaS es una aplicación web orientada a la gestión de clínicas veterinarias. Su objetivo es facilitar la administración de veterinarias, usuarios, propietarios, mascotas, citas médicas e historiales clínicos desde una plataforma centralizada.

El sistema incluye  perfiles de usuario, permitiendo controlar el acceso a las funcionalidades según los permisos asignados.

Tecnologías:
Frontend: Angular 21, TypeScript, HTML y SCSS.
Backend: Java 17 y Spring Boot 4.1.2.
Base de datos: Oracle Autonomous Database.
Autenticación: Microsoft Entra ID B2C.
Control de versiones:GitHub.

Estructura del repositorio
vetcloud-frontend: aplicación Angular.
vetcloud-backend: servicios REST desarrollados con Spring Boot.
database: scripts de base de datos.

Estado del despliegue

Actualmente el frontend y backend se ejecutan localmentem, la BD se encuentra alojada en Oracle Cloud.
